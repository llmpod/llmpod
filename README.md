**开源的私有化大模型推理基础设施**

LLMPod 帮助个人、团队和企业将自有算力上的模型交付为可用的推理服务。从接入服务器、导入模型，到部署、在线调试、发布 API，再到管理租户、配额和消费记录，都可以在同一个平台完成。

**让模型跑起来，让业务接得上，让资源和用量看得清。**

## 适用场景

| 你想做什么 | LLMPod 可以提供什么 |
| --- | --- |
| 搭建私有模型服务 | 在自有服务器上部署模型，为内部助手、智能体和业务系统提供统一 API |
| 为知识库应用提供模型能力 | 部署对话、Embedding 和 Rerank 模型，为应用提供生成、向量化与重排序接口 |
| 多个团队共享模型与算力 | 集中管理计算资源，按租户区分成员、模型访问范围、调用配额和消费记录 |
| 统一管理自建与外部模型 | 将本地推理服务和已有外部模型端点发布到同一网关，统一接入和观察调用情况 |

## 功能特性

### 集群与算力管理

把多台服务器的计算资源放到同一视图中，了解哪些设备可用、资源被哪些模型占用。

- **节点接入**：通过管理端生成接入命令，统一管理集群与计算节点，查看在线状态和资源信息。
- **设备监控**：支持 NVIDIA GPU、Ascend NPU 探测与监控，查看显存、利用率、温度等设备指标，以及节点 CPU、内存和磁盘状态。
- **资源拓扑**：展示集群、节点、设备与模型部署之间的关系，结合资源占用选择部署位置。

### 模型导入与部署

从模型文件到可调用服务，提供可视化的部署流程和状态追踪。

- **模型来源**：支持从 Hugging Face 或本地文件导入模型，提供模型信息探测、文件检查、大文件分片上传和节点分发。
- **部署预检**：根据模型和现有资源评估显存需求与兼容性，推荐引擎、镜像和部署配置，支持自动选卡或手动指定资源。
- **生命周期管理**：管理模型版本、部署实例与副本，执行启动、停止和重新启动，查看部署进度与容器日志。
- **多副本与扩缩容**：为同一模型运行多个服务副本；各副本配置一致的 GPU 部署可在线手动调整副本数，并预览可用资源与扩容上限。

### 多引擎与多种硬件

根据模型格式和现有设备选择推理引擎，在同一套管理流程下运行不同模型。

| 推理引擎 | 支持的设备 | 部署能力 |
| --- | --- | --- |
| vLLM | NVIDIA GPU、Ascend NPU | 单机部署；NVIDIA 环境支持多机部署 |
| SGLang | NVIDIA GPU | 单机及多机部署 |
| llama.cpp | NVIDIA GPU、CPU | GGUF 模型的单机 GPU 或纯 CPU 推理 |

支持单机多卡部署，提供按引擎、硬件架构和版本选择的推理镜像目录。具体可用的模型、并行方式及设备组合取决于所选镜像、驱动和运行环境。

### 统一 API 网关与服务发布

通过一个入口调用自建模型和外部模型服务，让业务应用使用统一的模型名称与访问凭据。

- **协议接入**：提供 OpenAI Chat Completions、Embeddings、模型列表，以及 Anthropic Messages、Token 计数和 Rerank 接口，支持对话流式响应。
- **模型发布**：使用模型别名对外提供服务，管理发布、下架及上游绑定；部署就绪后自动创建对应发布路由。
- **多端点路由**：同一模型别名可绑定多个服务端点，支持优先级、权重分流、会话亲和及可配置的失败切换。
- **统一鉴权**：通过 API Key 控制调用权限，记录请求流向和调用结果，便于接入现有 SDK 与业务应用。

### 多租户、配额与用量计费

让不同团队共用平台，同时分别管理访问权限、调用额度和调用成本。

- **团队与权限**：提供平台管理端和租户工作台，管理租户成员与角色权限，按租户隔离 API Key 和调用数据。
- **模型访问范围**：按租户配置模型访问限制，并进一步限定每个 API Key 可调用的模型。
- **精细配额**：支持每分钟请求数（RPM）、每分钟 Token 数（TPM）、总 Token、按模型 Token 配额，以及 Key 预算和有效期。
- **计量与定价**：统计输入、输出与缓存命中 Token，支持相应定价、租户余额、消费明细和用量查询，方便核算各团队的调用开销。

### 在线调试与模型验证

模型发布后，可以直接在浏览器中验证对话效果，再接入实际业务。

- **对话调试**：内置 Playground，支持多轮对话、流式输出，以及系统提示词、采样参数和输出长度调整。
- **模型切换**：选择已发布的对话模型测试效果；租户可使用自己的 API Key 验证实际访问权限和调用情况。
- **推理展示**：展示模型返回的回答与思考内容；具备视觉能力的模型可进行图文输入测试，具体能力取决于模型与引擎。

### 监控、日志与运维

同时观察算力使用和模型服务表现，从请求记录追踪到具体部署。

- **运行看板**：查看集群、节点、设备、部署副本与推理引擎状态，结合拓扑了解资源分布。
- **调用指标**：统计请求量、成功与失败情况、响应延迟、首 Token 延迟和 Token 用量，按模型、租户等维度观察使用情况。
- **问题排查**：提供请求日志、部署与容器日志、审计日志，追踪调用异常和管理操作。
- **指标接入**：提供 Prometheus 格式的 API 网关指标接口，便于接入已有监控系统。

## 快速开始

### 1. 安装平台

在目标 Linux 服务器上运行官方安装脚本，并按提示完成安装与初始化：

```bash
curl -fsSL https://llmpod.ai/src/download/install.sh -o install.sh && sudo bash install.sh
```

需要自行配置 Docker Compose、固定版本或升级现有部署时，请参阅 [Docker 部署指南](docs/usage/deployment.md)。

### 2. 接入算力并部署模型

1. 登录平台管理端，创建或选择集群。
2. 在节点管理中生成接入命令，在目标计算节点上执行，确认节点上线。
3. 从 Hugging Face 或本地文件导入模型，选择适配的推理镜像和计算资源，创建部署。
4. 等待实例就绪，确认自动创建的模型路由、发布别名和可用状态。
5. 创建租户并登录租户工作台，生成 API Key，按需设置模型访问范围与配额。调用计费模型时，需确保租户余额充足。

管理端负责平台配置，推理请求发送到独立的 API 网关。使用仓库中的 [Docker 配置模板](docker/.env.example) 时，管理端默认端口为 `18080`，API 网关为 `18090`；实际地址以部署配置为准。
